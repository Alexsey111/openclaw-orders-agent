# Демо на 90 секунд: что показать и в каком порядке

Запись одним куском, без монтажа и без озвучки поверх — только экран и голос.
Цель: незнакомый человек за 90 секунд понимает, что было, что стало и чем это проверено.

## Подготовка (до записи, в кадр не попадает)

```bash
# 1. ядро на отдельной базе прогона
cd "D:/python projects/AI_Freelance_Copilot"
DATABASE_URL="sqlite:///./data/live.db" LLM_PROVIDER=openai \
  ./.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8800

# 2. окно терминала — крупный шрифт, тёмный фон, ширина ~110 символов
cd "D:/python projects/openclaw-orders-agent"
python scripts/orders_ops.py health          # проверить, что ядро живо
```

Проверить до записи: в `.env` ядра ключ есть, но в кадр он не попадает — `.env` не открывать.
Один прогон на записи стоит ~1,24 ₽, повторная запись — ещё столько же.

## Кадр 1 (0:00–0:15). Что было

Экран: README на GitHub, раздел «Прогон 20 заказов на реальной модели».

Голос: «Разбор входящего заказа вручную — восемь минут: минута на поиск, семь на оценку
своих сил, сроков и цены. Двадцать заказов — это два часа сорок. Вот что получилось,
если эту рутину отдать агенту».

## Кадр 2 (0:15–0:45). Что делает система

Терминал, три команды подряд:

```bash
python scripts/orders_ops.py --timeout 180 triage --analyze --limit 25
python scripts/orders_ops.py queue
```

Голос: «Двадцать заказов, двадцать секунд работы модели. Десять — откликаться, семь —
на проверку человеку, три — пропустить. Очередь проверки: семь записей, каждая с причиной».

Показать в таблице две строки: одну «откликаться» с оценкой, одну «на проверку» с причиной.

## Кадр 3 (0:45–1:10). Где ошибается

Экран: `reports/latest-triage.md`, строка `fl-2411-012` и `fl-2411-010`.

Голос: «Система ошибается, и это видно: заказ на двадцать тысяч она предлагает взять,
хотя мой минимум — пятьдесят; заказ на вёрстку отправляет на проверку вместо отказа.
Три таких места записаны в README — их нашёл прогон на реальной модели, на заглушке
их не видно».

## Кадр 4 (1:10–1:30). Чем проверено и сколько стоит

Экран: README, строки с числами и команда запуска.

Голос: «Стоимость прогона — рубль двадцать четыре: двадцать тысяч входных токенов,
две тысячи семьсот выходных, тариф провайдера. Повторяется одной командой, база
и данные прогона лежат в репозитории. Дальше — резюме и десять откликов».

## Чего в кадре не делать

- Не открывать `.env`, настройки провайдера и личный кабинет.
- Не показывать файловый менеджер с чужими проектами — только терминал, README и отчёт.
- Не перезаписывать дубли: два дубля — два прогона, каждый по 1,24 ₽.
- Не обещать того, чего нет: отправка откликов не автоматизирована (ТЗ ядра §22),
  в кадре это говорить как ограничение, а не как «сделаю потом».
