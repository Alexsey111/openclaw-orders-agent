# n8n: низкокодовый вариант того же агента

Зачем это здесь. В вакансиях по автоматизации рядом с Python почти всегда стоит «n8n / Make /
Zapier». Аргумент «освою за неделю» проверяется одним вопросом, а ссылка на работающий workflow —
нет. Поэтому в этом каталоге лежит тот же разбор заказов, собранный в n8n, рядом с Python-версией:
одна задача, два пути, сравнение честное.

## Запуск (Windows, Docker Desktop)

```bash
cd "D:/python projects/openclaw-orders-agent/n8n"
docker compose up -d
```

Проверка: `curl -s http://localhost:5678/healthz` → `{"status":"ok"}`.
Интерфейс: http://localhost:5678 — при первом входе n8n просит создать локального пользователя
(почта и пароль хранятся только в этом контейнере, никуда не уходят).

Остановить: `docker compose stop`. Данные лежат в `n8n/data` (в git не попадают).
Удалить всё вместе с базой workflow: `docker compose down && rm -rf data`.

Порт 5678 держит один контейнер. Если он занят — сначала `docker compose stop` в этом каталоге
или погасить чужой процесс на 5678.

## Что внутри

- `docker-compose.yml` — один сервис n8n, том `./data`, часовой пояс UTC+7.
- `workflows/triage-orders.json` — разбор всех новых заказов из ядра (20 за 40 с).
- `workflows/intake-webhook.json` — приём одного заказа по `POST /webhook/orders/intake`
  с ответом «решение + черновик»; активен, порт 5678.
- `data/` — база n8n и ключ шифрования credentials, в git не попадает.

## Как workflow связан с ядром

Ядро AI_Freelance_Copilot поднимается на `http://127.0.0.1:8800` (лаунчер `scripts/run_live.ps1`).
Из контейнера n8n хост доступен как `http://host.docker.internal:8800`. Это важно: `127.0.0.1`
внутри контейнера — сам контейнер, а не Windows.

## Чем этот путь хуже и лучше Python-версии

Лучше: меняется без кода, видно глазами, не надо объяснять, где лежит цикл.
Хуже: нет тестов, правила ветвления живут в узлах и не покрыты pytest, отладка сложного JSON
в нодах хуже, чем в коде, и версии workflow не диффятся так читаемо, как код.

Поэтому в портфолио показываются оба пути: Python — как основной, n8n — как доказательство,
что инструмент в руках, а не в резюме.
